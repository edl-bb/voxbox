C

Onboarding in the dashboard's own type, not .system fonts.

The recording-mode step as shipped in 1.3, restyled with the Typography scale the rest of the app already uses: optical-size serif at 40, Source Sans body, progress dots, and cards that read as choices rather than features.

Why: onboarding is the only screen still using raw system fonts, so the first thing a new user sees is the least VoxBox-looking screen in the app.

D

The dashboard shows the last take, and what cleanup did to it.

History now stores the raw transcript next to the cleaned one, which makes a before/after diff cheap. Removed fillers strike through, added punctuation glows green, and the footer explains the guardrail ladder in one line.

Why: trust. Light cleanup went from “sometimes does nothing” to “usually lands”, and the fastest way to earn confidence in an editor is to show its edits.
